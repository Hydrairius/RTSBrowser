# Audio — data

Sound and music manifest for v0. Implementation loads this file from `@rtsbrowser/client` via `features/audio/data/sfx-manifest.json`.

## Manifest schema

| Field | Required | Description |
|-------|----------|-------------|
| `src` | yes | Public URL under `packages/client/public/` |
| `category` | yes | `"sfx"` or `"music"` — routed to the matching volume bus |
| `volume` | no | Per-clip multiplier (0–1), default `1` |
| `loop` | no | Loop playback (music tracks) |

## Asset naming

```
public/audio/
  music/          — looping tracks
  sfx/ui/         — clicks, menu open
  sfx/build/      — construction complete
  sfx/unit/       — train deploy
  sfx/sting/      — match end one-shots
```

Replace placeholder WAV files (generated by `../tools/generate-placeholders.mjs`) with final assets.

**Generate with AudioCraft:** see [`../tools/audiocraft/README.md`](../tools/audiocraft/README.md) — text-to-sound (AudioGen) for SFX, MusicGen for loops. Prompts in `../tools/audiocraft/prompts.json`.

## Dependencies

- **Upstream:** [ui-hud player journey](../../ui-hud/data/player-journey.md) — settings sliders (master / SFX / music)
- **Downstream:** client presentation layer only; simulation stays silent
